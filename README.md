# Sistem kafića

Seminarski projekat iz predmeta **Metodologija razvoja softvera**, izrađen tokom prve godine studija. Projekat prikazuje modelovanje sistema kafića i njegovih podsistema: šanka, kuhinje, magacina i parkinga.

## Sadržaj

- `Seminarski MET/Kafić/` — modeli i dijagrami izrađeni u PowerDesigner-u.
- `Seminarski MET/*.docx` — verzije seminarskog rada sa opisom sistema i dijagrama.

Modeli obuhvataju dijagrame slučajeva korišćenja, aktivnosti, stanja, sekvenci, klasa i objekata, kao i konceptualni, logički i fizički model podataka.

## Otvaranje projekta

Seminarski radovi se otvaraju u programu koji podržava `.docx` format. Fajlovi modela, kao što su `.oom`, `.cdm`, `.ldm` i `.pdm`, otvaraju se u **SAP PowerDesigner-u**.

> Ovo je projekat modelovanja sistema, a ne aplikacija koja se pokreće.
